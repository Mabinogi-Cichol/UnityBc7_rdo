# v0.5.0：RGBM 跨版本 Hook 与 Worker 参数分流

Editor Plugin 的 RGBM 分类改为认证当前 Unity 映像的私有接口，移除 f1 固定 RVA 和 JobData 偏移。Windows x64 的 Unity **2022.3.62f1／2022.3.62f2** 使用同一套插件，已验证 Editor、batchmode 和真实 AssetImportWorker。

- 匹配 PDB 优先，缺少 PDB 时采用受限扫描；按 exe SHA256 缓存并逐进程重新认证，不将未知 ABI 或歧义入口当作支持。
- 两点语义 Hook 采用事务安装，关联并发 Job／Worker 上下文；启用分类后的 Unknown／Unavailable 走 Unity 原生 BC7，严重恢复错误非零退出。
- RGBM 与普通纹理独立选择 Oodle lambda／ERT 参数；零 λ、继承、Oodle 缺失回退及 RGBM metric 经过实际编码验证。
- C# 绑定准备合入单个 `hook_loader.cs`；原生主 DLL、coordinator、gate 及 `RgbmBindings~` 仍须完整保留。DLL 合并另记 TODO。

本版保留两个独立下载包：

1. **Editor Plugin**：将包内容放入工程 `Assets/Plugins/Bc7Rdo` 等目录，保留 asmdef、三个 DLL、`RgbmBindings~` 和许可目录。从含独立 `rgbm_bindings_loader.cs` 的版本升级时，先关闭 Editor／Worker并删除旧脚本及其 meta，避免重复类型。保留已有配置，需 RGBM 分流时改 `unity_rgbm_context_hooks=1` 后重开；发布示例默认仍为 `0`。
2. **壳 DLL**：沿用 Unity 安装目录替换／回滚方案。此次新增的 RGBM 语义分类属于 Editor Plugin，壳包不提供该分类能力。

包内提供递归 SHA256 与 bc7enc_rdo／Detours 许可。私有 release DIA 未修改，分发条件见 [Microsoft DIA 再分发列表](https://learn.microsoft.com/en-us/visualstudio/releases/2026/redistribution#dia-sdk)及包内说明。**不包含 Oodle、Unity exe／PDB／原始 DLL、测试资源或运行缓存**；Oodle 用户需自行从获授权 SDK 提供两份运行库。

P5 完整验收共 14 次 Unity 运行、1,140 份输出、20,520 次编码调用和 391,020 个块，570 组主进程／Worker 输出一致；原生配置首次读取回归为 120 进程×64 线程。C# 合并后另有 f1／f2 主进程和 Worker 四轮验证。发行产物重新构建后的验证另见 P6 交付记录，不能将旧 DLL 的完整 P5 计数直接算作发行二进制的重跑结果。

支持与实测边界：其他 Editor 构建仍需认证，未保证适配；无 VS 环境按用户要求未测试；严格 Unity 内先 Ready 后首次 BC7 加载场景未实测。已有解码误差只表示相对原生 BC7 的差异，未提供源 HDR 视觉质量或纯 Hook 开销保证。更换／卸载 DLL 必须关闭目标工程及 Worker。
